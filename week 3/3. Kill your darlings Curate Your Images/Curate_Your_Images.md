### Why Real Captures Win for Engineering Work:
- **Empirical Credibility**: ML hiring managers inspect charts for real axes, labels, baseline curves, and actual model iterations. An AI-generated synthetic chart has fake numbers, destroying technical credibility.
- **Authenticity**: Using real Matplotlib outputs generated during python execution proves that code was actually run on a 79M-row production dataset.
